# 1. 將所有變更或新增的檔案加入暫存區
git add .

# 2. 提交變更並加上說明訊息（建議使用英文）
git commit -m "feat: update code from new computer"

# 3. 將更新推送到 GitHub 遠端倉庫
git push origin main

# 4.將遠端變更抓回本地並整合
git pull origin main --allow-unrelated-histories
(註：如果此時跳出黑色文字編輯畫面，請依序按 Esc 鍵、輸入 :wq、然後按下 Enter 離開。)

# 5.重新推送到 GitHub
git push -u origin main
